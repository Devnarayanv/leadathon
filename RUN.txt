 3. STOP
----------------------------------------------------------------
Click the terminal window and press  Ctrl + C   (in each terminal).

If Ctrl+C does not free the port, kill by port:
  Get-NetTCPConnection -LocalPort 8000 | Select-Object -Expand OwningProcess | ForEach-Object { Stop-Process -Id $_ -Force }
  Get-NetTCPConnection -LocalPort 5173 | Select-Object -Expand OwningProcess | ForEach-Object { Stop-Process -Id $_ -Force }

See what is holding a port:
  Get-NetTCPConnection -LocalPort 8000 | Format-Table LocalPort,State,OwningProcess

Blunt version (kills every python / node on the machine):
  Stop-Process -Name python -Force
  Stop-Process -Name node   -Force


----------------------------------------------------------------
 4. RESTART
----------------------------------------------------------------
BACKEND
  Code changes in backend\*.py   -> nothing to do, --reload restarts it.
  Changes in .env                -> Ctrl+C, then run uvicorn again.
  Changed OLLAMA_MODEL           -> Ctrl+C, then run uvicorn again.
  Installed espeak-ng / Tesseract-> Ctrl+C, then run uvicorn again.

FRONTEND
  Code changes in src\           -> saves hot-reload by themselves.
  Changed vite.config.js         -> Ctrl+C, then: npm run dev
  Installed a new npm package    -> Ctrl+C, npm install, npm run dev

OLLAMA
  ollama ps        (what is loaded)
  ollama stop <model-name>
  ollama serve     (start it again)

FULL RESET (everything, in order)
  1. Ctrl+C in both terminals
  2. kill-by-port commands from section 3 if ports are stuck
  3. Terminal 1: cd C:\Devan\Projects\leadathon; .\.venv\Scripts\Activate.ps1; cd backend; uvicorn main:app --reload --port 8000
  4. Terminal 2: cd C:\Devan\Projects\leadathon\frontend; npm run dev
  5. Hard-refresh the browser:  Ctrl + Shift + R

----------------------------------------------------------------
 8. QUICK FIXES
----------------------------------------------------------------
"The backend is not reachable"
  -> uvicorn is not running, or you opened 127.0.0.1 instead of localhost.

"Ollama is not reachable"
  -> ollama serve   (or start the Ollama desktop app)

"Model X is not installed"
  -> ollama list, then ollama pull <model>, then restart the backend.

Port 8000 already in use
  -> use the kill-by-port command in section 3, or run on another port:
     uvicorn main:app --reload --port 8001
     (then update the proxy target in frontend\vite.config.js)

Blank page after npm run dev
  -> npm install did not finish. Run it again. If npm warns about the
     esbuild install script:
     cd frontend; npm install-scripts approve esbuild

Explanations time out
  -> raise OLLAMA_TIMEOUT in .env, or lower MAX_EXPLAINED_CLAUSES,
     then restart the backend.

No Malayalam audio
  -> winget install eSpeak-NG.eSpeak-NG   then restart the backend.

"Tesseract OCR was not found"  (only matters for scans/photos)
  -> install Tesseract, then set in .env:
     TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe
     and restart the backend.

Nothing makes sense any more
  -> full reset (section 4) + Ctrl+Shift+R in the browser.
